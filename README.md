# 语言教学统计助手

一个本地优先的轻量前端 MVP，先解决老师最常用的三件事：

1. 记录学生的上课内容、课后作业和作业完成度。
2. 汇总每月排课课时和已完成课时。
3. 追踪剑雅题目，避免学生重复做题，并给出下次可布置题目的建议。

## 打开方式

这是一个纯静态网页，数据保存在浏览器 `localStorage`，不需要后端服务也可以使用。

### 方式一：直接打开文件

双击或在浏览器里打开 [index.html](./index.html)。

适合日常本地使用。地址会显示为 `file:///.../index.html`，不占用端口，也不会因为本地服务关闭而打不开。

### 方式二：固定使用 5500 端口

如果你希望固定使用下面这个地址：

`http://127.0.0.1:5500/index.html`

运行项目根目录下的 `start-localhost-5500.command`。

脚本会先检查 `5500` 端口：

1. 如果端口已经有服务在运行，会直接提示打开上面的地址。
2. 如果端口空闲，会启动本地服务并绑定到 `127.0.0.1:5500`。
3. 服务窗口需要保持打开；关闭窗口或按 `Control-C` 会停止本地服务。



## 当前功能

1. `总览`
   - 查看学生总数、本月排课课时、本月已完成课时、待跟进项目。
   - 查看最近课程记录和未完成作业/未完成题目。
2. `学生`
   - 新增、编辑、删除学生。
   - 记录考试类型、目标分数、当前阶段和备注。
3. `课程记录`
   - 记录排课或已完成课程。
   - 填写上课内容、课后作业、作业完成度。
   - 分开记录“本次已完成的题目”和“下次布置的题目”。
4. `剑雅追踪`
   - 按学生、模块、套数查看题目状态。
   - 自动区分“已完成”“已布置”“未使用”。
   - 自动推荐下一个未触达题目。

## 数据说明

1. 所有数据保存在浏览器 `localStorage`。
2. `file://` 和 `http://127.0.0.1:5500` 是两个不同的浏览器存储位置，切换打开方式时不会自动共享数据。
3. 切换打开方式前，先用页面右上角按钮导出 `json` 备份，再到另一种打开方式里导入。
4. 可通过导入按钮恢复数据。

## 题目格式

推荐输入格式：

- 听力：`C16-Test3-Part1`
- 阅读：`C14-Test2-Passage3`

系统会自动兼容常见写法，比如带空格或大小写不同的输入。
