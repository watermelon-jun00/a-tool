# 语言教学统计助手

一个本地优先的轻量前端 MVP，先解决老师最常用的三件事：

1. 记录学生的上课内容、课后作业和作业完成度。
2. 汇总每月排课课时和已完成课时。
3. 追踪剑雅题目，避免学生重复做题，并给出下次可布置题目的建议。

## 打开方式

这是一个纯静态网页，数据保存在浏览器 `localStorage`，不需要后端服务也可以使用。

### 方式一：直接打开文件

双击或在浏览器里打开 [index.html](./index.html)。

适合日常本地使用。地址会显示为 `file:///.../index.html`，不占用端口，也不会因为本地服务关闭而打不开。

### 方式二：固定使用 5500 端口

如果你希望固定使用下面这个地址：

`http://127.0.0.1:5500/index.html`

运行项目根目录下的 `start-localhost-5500.command`。

脚本会先检查 `5500` 端口：

1. 如果端口已经有服务在运行，会直接提示打开上面的地址。
2. 如果端口空闲，会启动本地服务并绑定到 `127.0.0.1:5500`。
3. 服务窗口需要保持打开；关闭窗口或按 `Control-C` 会停止本地服务。

## 本地运行排查

1. `file://` 能打开，但 `5500` 不能打开：
   - 先运行 `start-localhost-5500.command`。
   - 确认终端里没有报错。
   - 如果提示端口已在运行，直接访问 `http://127.0.0.1:5500/index.html`。
   - 如果提示 `Port 5500 is already in use, but it does not look like this site.`，说明 5500 被别的本地服务占用了；先关掉那个服务，或直接用 `file://` 方式打开。
2. 页面看起来还是旧版本：
   - 先强制刷新浏览器。
   - 本页面已给 `style.css` 和 `app.js` 增加版本参数，避免浏览器继续加载旧缓存。
   - 如果你改的是 GitHub Pages 公网版本，确认已经重新运行 `sync-github-pages-docs.command`，并把 `docs/` 里的文件一起提交推送。
3. 切换 `file://` 和 `5500` 后数据不一样：
   - 这是正常现象，两个地址的 `localStorage` 互相独立。
   - 从原来的打开方式里先导出 `json`，再到新的打开方式里导入。
4. 页面空白或按钮失效：
   - 打开浏览器开发者工具 Console，先看是否有红色 `ReferenceError` 或 `TypeError`。
   - 常见原因是 HTML 元素 id 和 `app.js` 里的 `getElementById` 不一致，或浏览器仍在运行旧的 `app.js` 缓存。

## 当前功能

1. `总览`
   - 查看学生总数、本月排课课时、本月已完成课时、待跟进项目。
   - 查看最近课程记录和未完成作业/未完成题目。
2. `学生`
   - 新增、编辑、删除学生。
   - 记录考试类型、目标分数、当前阶段和备注。
3. `课程记录`
   - 记录排课或已完成课程。
   - 填写上课内容、课后作业、作业完成度。
   - 分开记录“本次已完成的题目”和“下次布置的题目”。
4. `剑雅追踪`
   - 按学生、模块、套数查看题目状态。
   - 自动区分“已完成”“已布置”“未使用”。
   - 自动推荐下一个未触达题目。

## 数据说明

1. 所有数据保存在浏览器 `localStorage`。
2. `file://` 和 `http://127.0.0.1:5500` 是两个不同的浏览器存储位置，切换打开方式时不会自动共享数据。
3. 切换打开方式前，先用页面右上角按钮导出 `json` 备份，再到另一种打开方式里导入。
4. 可通过导入按钮恢复数据。
5. 如果页面仍显示旧学生数据，通常不是代码没有更新，而是当前浏览器地址下仍保存着旧的 `localStorage`。先导出备份，再在浏览器开发者工具里清理该站点的本地存储，或换一个新的浏览器/隐身窗口测试。
6. `student-import-template.xlsx` 只保留表头和填写说明，不包含任何学生样例行。

## 隐私与发布安全

1. 当前 GitHub Pages 站点是公开静态网页，任何拿到网址的人都可以打开。
2. 网页不会把你的本机 `localStorage` 自动发布给别人；每位访问者看到的是自己浏览器里的本地数据。
3. 不要把真实学生姓名、联系方式、微信、手机号、作文内容或详细课堂备注提交到 GitHub 仓库。
4. 导出的 JSON、CSV、Excel 都可能包含学生信息，应当当作敏感文件保存和传递。
5. 云端同步默认不预填 Supabase URL 或 anon key；只有你手动填写连接信息并登录后，才会尝试同步到云端。
6. 如果未来要长期保存真实学生数据，请先确认 Supabase RLS 权限规则已经启用并通过测试，再开放给多人使用。

## 题目格式

推荐输入格式：

- 听力：`C16-Test3-Part1`
- 阅读：`C14-Test2-Passage3`

系统会自动兼容常见写法，比如带空格或大小写不同的输入。
