# 语言教学统计助手

面向教师的轻量教学管理工具，能把学生档案、课程记录、排课、实考成绩和剑雅材料进度放在同一个工作台里，减少重复表格和人工核对。

**在线体验：** [watermelon-jun00.github.io/a-tool](https://watermelon-jun00.github.io/a-tool/)

> 公开站点默认是空白工作台。点击“示例数据”可以体验完整流程，示例内容均为虚构数据。

## 能解决哪些问题

- 学生和试听信息分散，跟进容易遗漏。
- 每月排课、已完成课时和待处理事项需要人工汇总。
- 剑雅题目重复布置，课程记录难以连续追踪。
- 学生多次雅思实考后，成绩变化不够直观。

## 核心功能

- 学生档案：考试类型、基础、目标分数、课程套餐、班级和备注。
- 试听管理：预约、跟进、转正和试听数据导出。
- 课程记录：排课状态、课堂内容、作业、教材题目和课程反馈。
- 课程表：按日期查看个人课与班课安排。
- 材料追踪：区分已完成、已布置和未使用题目。
- 实考成绩：可选上传成绩截图，并对比首次与最近一次成绩。
- 数据迁移：JSON 备份/恢复，以及简化的三表 Excel 学生台账。

## 快速上手

1. 打开在线体验地址，点击“示例数据”查看完整效果。
2. 点击“学生”新增自己的测试学生，或下载 `student-import-template.xlsx` 批量导入。
3. 在“课程录入”添加一节课，再到“工作台”“课程表”“材料追踪”查看联动结果。
4. 正式录入前先阅读下方的数据与隐私说明。

## 数据与隐私

- 当前版本是本地优先的静态网页，业务数据保存在访问者自己的浏览器 `localStorage`，不会自动写入 GitHub 仓库。
- 本次隐私版本启用了新的存储空间；公开站点首次打开时会删除旧版学生数据和旧云端登录配置，不再迁移历史学生记录。

## 本地运行

最简单的方式是直接打开根目录的 `index.html`。

需要固定地址时，双击 `start-localhost-5500.command`，然后访问：

`http://127.0.0.1:5500/index.html`

页面修改后，运行 `sync-github-pages-docs.command`，把根目录的发布文件同步到 `docs/`。

## 技术实现

- 原生 HTML、CSS、JavaScript，无框架依赖。
- `localStorage` 本地持久化，静态文件可由 GitHub Pages 托管。
- 可选 Supabase 连接仅接受官方 HTTPS 项目域名。
- 发布检查脚本会核对 JavaScript 语法、发布目录一致性、页面元素引用和敏感文件。

## 动态化路线

该项目可以升级为支持账号、多设备同步和私有截图存储的动态应用。推荐使用“前端托管 + Supabase Auth/Postgres/Storage”，并通过 RLS 做用户级数据隔离。具体要求和部署步骤见 [DYNAMIC_DEPLOYMENT.md](./DYNAMIC_DEPLOYMENT.md)。
